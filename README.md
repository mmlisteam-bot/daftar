# Daftar

دفتر شخصی جزوه‌های پنتست وب — شبیه Notion، با صفحات تو‌در‌تو، تگ، جستجو، بلاک و اسکرین‌شات.

همه چیز داخل مرورگر ذخیره می‌شود (localStorage / IndexedDB). سرور و حساب کاربری لازم نیست.

## اجرا روی سیستم خودت

```bash
npm install
npm run dev
```

## استفاده

- `Ctrl + K` جستجو
- `/` منوی بلاک
- تگ‌ها در سایدبار برای فیلتر (مثلاً SQL Injection)
- خروجی Markdown / چاپ PDF / پشتیبان JSON

## جزوه نمونه

صفحات HTTP و چهار مدل SQL Injection از قبل داخل دفتر هستند.
